STRATEGY KNOWLEDGE

策略知识与白盒字段

九字段将模型信号、策略条件和处置动作放进同一个可比结构，是 Agent 给出可执行结论的基础。

01 / DOMAIN

问题域

风险属于哪一治理领域，用于限制候选策略范围。

02 / OBJECT

识别对象

评论、图评、视频、用户或评论区整体。

03 / CONDITION

管控条件

策略生效需满足的内容、行为与上下文条件。

04 / SIGNAL

识别信号

词库、模型、OCR、ASR、画像等证据来源。

05 / VERSION

模型 / 策略版本

回放时锁定当时实际生效的配置版本。

06 / RISK

风险等级

统一高、中、低风险的判断与升级条件。

07 / RESULT

策略结果

命中、未命中、豁免或信息不足。

08 / ACTION

处置动作

放行、折叠、拦截、送审或二次确认。

09 / SCOPE

生效范围

人群、场景、流量、时间与实验桶约束。

候选策略排序逻辑：问题域一致性 → 对象一致性 → 条件满足度 → 版本与范围有效性 → 处置映射。
